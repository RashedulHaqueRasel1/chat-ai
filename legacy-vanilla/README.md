# 🎬 CineText AI - Text to Video Studio

একটি আধুনিক, রেসপন্সিভ এবং প্রিমিয়াম **Text-to-Video AI Studio** ওয়েব অ্যাপ্লিকেশন। এখানে টেক্সট প্রম্পট লিখে সিনেমাটিক HD ভিডিও জেনারেট করা যায়।

---

## 🌟 সুবিধাসমূহ (Features)
1. **সিনেমাটিক ডার্ক মোড ডিজাইন:** Glassmorphic ইফেক্ট এবং আধুনিক অ্যানিমেশন।
2. **ফ্রি ডেমো মোড (Instant Preview):** কোনো API Key ছাড়াই দ্রুত ফিচার টেস্ট করার সুবিধা।
3. **Fal.ai API ইন্টিগ্রেশন:** MiniMax Hailuo এবং Wan 2.1 এর মতো শক্তিশালী মডেলের লাইভ সাপোর্ট।
4. **ভিজুয়াল স্টাইল সিলেকশন:** Cinematic, Anime, Photorealistic এবং Fantasy 3D।
5. **অ্যাসপেক্ট রেশিও:** 16:9 (YouTube Landscape) এবং 9:16 (Shorts/TikTok)।
6. **রিসেন্ট গ্যালারি:** তৈরি করা ভিডিওগুলোর হিস্ট্রি এবং সরাসরি ডাউনলোড (MP4) করার ব্যবস্থা।

---

## 🔑 যেভাবে ফ্রি API Key সংগ্রহ করবেন

### উপায় ১: Fal.ai থেকে ফ্রি Key নেওয়া (প্রস্তাবিত)
1. ব্রাউজারে [https://fal.ai/](https://fal.ai/) এ যান।
2. **Sign Up** এ ক্লিক করে আপনার GitHub বা Google অ্যাকাউন্ট দিয়ে লগইন করুন।
3. লগইন করার সাথে সাথে ডেভেলপার হিসেবে ফ্রি টেস্ট ক্রেডিট পেয়ে যাবেন।
4. [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) এ গিয়ে **Create Key** বাটনে ক্লিক করে Key কপি করুন।
5. আপনার তৈরি করা ওয়েবসাইটে গিয়ে উপরে **"API Key সেট করুন"** বাটনে ক্লিক করে পেস্ট করে **Save** করুন।
